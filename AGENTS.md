# Project documentation

This repository maintains its documentation in [docs/index.md](docs/index.md), including links to the skills and their reference guides.

Before work, read the index and the sources relevant to the task. Inspect the actual instructions and other evidence before changing claims; distinguish current behavior, future plans and historical context.

After a meaningful change, assess documentation impact and update only affected sources. Keep the index complete when documents are added, renamed, removed or change status. A change that preserves meaning may need no documentation update; report why.

Keep the shared method consistent across the setup skill, maintenance skill, reference guides and standalone prompt when its rules change. Preserve useful content and local changes, use English in this repository, and check changed links and the diff before reporting completion. A focused maintenance task does not by itself authorize reorganizing all documentation.
